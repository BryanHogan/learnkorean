Korean sentence structure is different from English, so how does the sentence order in Korean look like?

## Sentence structure in Korean

This is the normal English sentence structure:  
**I** (*subject*) **like** (*verb*) **pizza** (*object*).

In Korean it would be:  
**I** (*subject*) **pizza** (*object*) **like** (*verb*) .

So the Korean structure is: **Subject Object Verb**  
While English has this structure: **Subject Verb Object**
