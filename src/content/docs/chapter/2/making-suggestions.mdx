How to make suggestions in Korean?

In Korean there are several ways to make suggestions, many depend on how polite you want to be.

## Saying `let's`

Saying `let's` is suggesting that someone else does something together with you.

For acquaintances and in non-formal situations you can use the adverb `같이` (together) with the present tense `요` form: `같이 + 요 Form`

<Sentence
    ko="**같이** 가요"
    en="Let's go (together)."
/>
<Sentence
    ko="**같이** 밥 먹어요"
    en="Let's eat (together)."
/>

## Saying `shall we`

Another common way to make a suggestion is by asking `Shall we?` or `Shall I?`.

`Verb Stem + (을/ㄹ)까요`

1. Get the verb stem.
2. Depending on the ending:
    - If it ends in a consonant: Attach `을까요`.
    - If it ends in a vowel: Attach `ㄹ까요`.
    - However, if it ends in a `ㄹ`: Attach `까요`.
    - However, for `ㅂ`-irregular verbs: Remove `ㅂ`, then attach `우`, then `ㄹ 까요`.

Example sentences:

<Sentence
    ko="어디 **갈까요**?"
    en="Where shall we go?"
/>
<Sentence
    ko="과일을 **먹을까요**?"
    en="Shall we eat fruit?"
/>
<Sentence
    ko="뭘 **만들까요**?"
    en="What shall we make?"
/>

### Honorific `let's`

When making a suggestion to someone else you are also talking about them, it's like saying `(We) do (verb) together`.

For situations where you want to be extra polite and would use honorific speech, you can combine the honorific ending `(으시다)` with `Shall we?`. Because you are suggesting doing something together, you are also talking about the other person's actions, making honorifics appropriate.

<Sentence
    ko="같이 식사하러 **가실까요**?"
    en="Shall we go eat a meal together?"
/>

## Saying `let's` in casual speech (반말)

When using [casual speech (반말)](/chapter/casual-speech) there's another way to say `let's`. Attach `자` after an action verb stem:

`Action Verb Stem + 자`

Example sentences:

<Sentence
    ko="저녁 먹으러 **가자**."
    en="Let's go eat dinner."
/>
<Sentence
    ko="조금 어 **공부하자**."
    en="Let's study a little bit more."
/>
<Sentence
    ko="같이 **놀자**!"
    en="Let's hang out together!"
/>




## Saying `let's` using `읍시다`

Another way to say let's is by using `읍시다`. This grammar form is only used when a higher ranking person speaks to a lower ranking person, e.g. when a group leader speaks to the group members.

`Verb Stem + (읍 / ㅂ) 시다`

1. Get the verb stem.
2. Depending on the ending:
    - If it ends in a consonant: Attach `읍시다`.
    - If it ends in a vowel: Attach `ㅂ시다`.
    - However, if it ends in a `ㄹ`: Remove `ㄹ`, then attach `ㅂ시다`.
    - However, for `ㅂ`-irregular verbs: Remove `ㅂ`, then attach `우`, then `ㅂ시다`.

Regular `ㅂ` stems keep `ㅂ`: 입다 → 입읍시다.

Examples:

- 먹다 → 먹읍시다
- 가다 → 갑시다
- 만들다 → 만듭시다
- 돕다 → 도웁시다

Example sentences:

<Sentence
    ko="같이 밥을 **먹읍시다**."
    en="Let's eat together."
/>
<Sentence
    ko="서로 **도웁시다**."
    en="Let's help each other."
/>
