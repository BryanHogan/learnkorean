`이렇다`, `그렇다` and `저렇다` are used the same way as `이`, `그` and `저`.

> 이-, 그-, and 저- point to something near the speaker, near the listener or already mentioned, and away from both. They work the same way.

They are descriptive verbs meaning:
- `이렇다`: to be like this
- `그렇다`: to be like that
- `저렇다`: to be like that over there

## The different forms of `이렇다`, `그렇다` and `저렇다`

| 이렇다 | 그렇다 | 저렇다 |
| --- | --- | --- |
| 이렇게: Like this | 그렇게: Like that | 저렇게: Like that |
| 이런: This kind of | 그런: That kind of | 저런: That kind of |
| 이래요: It's like this | 그래요: It's like that | 저래요: It's like that |
| 이랬어요: It was like this | 그랬어요: It was like that | 저랬어요: It was like that |

## Examples

<Sentence
  ko="**이렇게** 하세요."
  en="Do it like this."
/>

<Sentence
  ko="저는 **그런** 영화를 좋아해요."
  en="I like that kind of movie."
/>

<Sentence
  ko="오늘 날씨가 왜 **이래요**?"
  en="Why is the weather like this today?"
/>

<Sentence
  ko="저 사람은 어제도 **저랬어요**."
  en="That person was like that yesterday too."
/>
