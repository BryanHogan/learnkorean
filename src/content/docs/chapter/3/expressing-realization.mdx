---
title: "Expressing Realization"
description: How to express realization using the 군요 ending.
---

To express realization use `군요` at the end of the sentence.

## How to use `군요` to express realization

`Verb stem + 군요`

1. Get the verb stem.
2. Attach `군요`.
    - However, if it's an action verb in present tense, attach `는군요` instead. E.g. `하다` → `하는군요`.
    - If an action verb stem ends with a `ㄹ`, remove the `ㄹ` and then attach `는군요`.
    - In [casual speech](/chapter/casual-speech) the `요` is not added.

## Example sentences

<Sentence
    ko="좀 **이상하군요**."
    en="That's a little strange (and I've just realized it)."
/>
<Sentence
    ko="**그렇군요**."
    en="It is so (and I've just realized it)."
/>
<Sentence
    ko="역시 오늘도 **잊었군**."
    en="Not surprisingly you forgot today too (and I've just realized it)."
/>
