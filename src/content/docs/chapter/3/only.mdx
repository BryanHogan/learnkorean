---
title: "Only"
description: Saying "only" in Korean using 만 and 밖에.
---


There are multiple ways to say "only" in Korean. The two most common ways are:

- 만
- 밖

## Saying "only" using 만

`만` can be attached directly after a word, it's a particle. So it can attach directly to the subject or object of the sentence.

**Examples**:

<Sentence
  ko="저는 김치**만** 좋아해요."
  en="I like only kimchi"
/>

<Sentence
  ko="저**만** 김치 좋아해요."
  en="Only I like kimchi"
/>

It can also be used between verbs that use `하다` with a noun.

**Examples**:

<Sentence
  ko="공부**만** 해요."
  en="I only study"
/>

`만` usually takes the place of any marker (like object marker, topic marker, subject marker). But it can be used together with the marker, in that case it's placed before the marker, although this usage is less common, for example: `만은`, `만을` or `만이`.

## Saying "only" using 밖

We already know that `밖` means `outside`. For example:

<Sentence
  ko="이안 씨는 **밖**에서 놀고 있어요."
  en="Ian is playing outside"
/>

But `밖` can also be used with the particle `에` and a negative verb to mean "only".

**Formula for 밖:**

1. Attach 밖에 directly after the noun without a space.
2. Finish the sentence with a negative verb.

**Examples**:

<Sentence
  ko="저는 영어**밖에** 할 수 없어요."
  en="I only speak English"
/>

<Sentence
  ko="저는 만 원**밖에** 없어요."
  en="I only have 10.000 Won"
/>

<Sentence
  ko="저는 이거**밖에** 몰라요."
  en="I only know this"
/>

<Sentence
  ko="한 명**밖에** 안 했어요."
  en="Only one person did this"
/>

The `밖에` form **cannot** be used with `아니다`. It can also **not** be used with commands or suggestions.

## Differences between 만 and 밖

Let's use this example:

A) 저는 채소만 먹어요.  
B) 저는 채소밖에 안 먹어요.

Both of these forms have the same English translation, both mean "I only eat vegetables".

But option B sounds more natural.

`밖에` has extra emphasis that something is **lacking or missing**. `만` does not have this emphasis.

So option B sounds more like the speaker is saying that eating only vegetables isn't enough for them and that they maybe want to eat other things too.
